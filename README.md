# Irving · 语音增强

为 DSH 内置语音输入服务增加持续听写、语音口令、草稿润色和远程 ASR 配置，并通过 TTS 朗读模型回复。

## 能做什么

- 持续说出多句话，识别结果逐句写入原生输入框，由你检查后发送。
- 用整句口令发送、撤销、清空、润色、停止听写、朗读或停止朗读，可禁用或设置文字前缀。
- 配置本地 SenseVoice、硅基流动或火山识别；火山 Agent Plan 流式服务支持临时识别预览。
- 手动朗读最新回复，或单独开启自动朗读；代码默认跳过，表格和长列表可按规则摘要。
- 在官方语音详情中配置服务、语言、模型、音色、凭据引用及高级参数。

## 安装

当前本地版本 **0.2.1-rc.2+rev.1**，要求 **DSH Desktop 0.2.1-rc.2**，并启用同版本官方语音输入 Bundle。官方语音五包的实际版本需要匹配，详见 [安装与版本](docs/INSTALL.md)及 [本次兼容记录](docs/DSH-UPGRADE-20261017.md)。

截至 2026-10-18，[公开源码仓库](https://github.com/irvingzhang0512/dsh-chatty)默认分支包版本为 **0.1.0**，当前 Desktop 适配版尚未公开推送或发布。

1. 先在「插件」启用官方「语音输入」，向维护者获取当前版本的完整预构建 `.tgz`。
2. 在「插件 → 添加插件 → 安装第三方插件」填写安装包的本机绝对路径。核对安装名 **`@irvingzhang0512/dsh-chatty`** 和完整版本后启用，按提示重启 DSH。
3. 进入官方「语音输入」详情，确认原设置下方出现 Chatty 增强配置。已安装本版的用户可直接配置。

当前没有本版公开下载链接，请勿将未发布 tag、短包名或旧默认分支作为本版来源。

## 配置

主要入口是「插件 → 语音输入」详情，Chatty 自身详情也提供跳转。官方上方设置选择识别服务和语言，下方 Chatty 分区配置听写、口令、润色和朗读，高级 API／本地模型参数默认折叠。

| 使用方式 | 首次使用前要做什么 |
|---|---|
| 本地识别 | 选择本地服务，按界面「准备模型」，确认依赖与模型就绪 |
| 远程 ASR | 选择已支持的服务，配置该服务要求的地址、模型和凭据引用 |
| TTS 朗读 | 选择可用语音输出服务、音色及相应凭据 |
| 草稿润色／模型摘要 | 配置可用模型；这些操作会发起模型请求 |

通过界面的「管理 DSH 凭据」保存密钥，插件设置只填写引用名。云端服务的账号条件、协议和凭据不同，远程配置不代表支持任意 ASR 协议。

各分区分别保存；未保存的草稿不会因切换标签丢失。按保存提示停止正在进行的语音任务，再重新加载对应服务。完整设置见 [配置界面说明](docs/CONFIG-UI.md)，本版新增官方字段以 [兼容记录](docs/DSH-UPGRADE-20261017.md)为准。

## 第一次使用

1. 按上节准备一个识别服务，打开会话，点击听写按钮，授予麦克风权限。
2. 说「今天先整理项目进展」，停顿，再说「重点检查还没有确认的问题」。两句话应依次出现在原生输入框。
3. 检查并手动修改文字，再点击原生发送。停顿只结束一句，不会自动发送；开启发送口令后，明确口令也可提交。
4. 点击停止以收尾末句。若要放弃本次尚未完成的识别，使用 dock 中的取消。
5. 配置 TTS 后，等模型生成回复，再点击朗读按钮核对声音；自动朗读需要单独开启，朗读本身不会自动开麦。

## 常用操作

| 想做什么 | 怎么做 | 结果 |
|---|---|---|
| 长段输入 | 开启持续听写，分句说话 | 多句累积为同一份输入草稿 |
| 避免口令误触 | 在口令设置中启用文字前缀或关闭口令 | 只识别符合规则的整句口令 |
| 整理口述草稿 | 使用润色操作，核对结果后采纳 | 用模型整理当前草稿 |
| 连续听回复 | 单独启用自动朗读 | 后续回复按输出规则朗读 |

## 使用边界

- 原生输入框是唯一正文。识别等待期间如果你改动正文，冲突结果会保留待处理，不覆盖手写内容。
- 本地 SenseVoice 和硅基流动按分句识别；临时预览取决于真实流式服务，不能要求所有服务都逐字返回。
- 官方输入设备与 Chatty 自身采集设备是各自的设置，需核对实际使用的设备。
- 本版没有完整语音对话、识别后自动发送、声学唤醒或完整回声消除。
- 旧版配置若触发迁移提示，先预览、处理冲突并备份，详见 [迁移说明](docs/CONFIG-LEGACY.md)。当前有效设置不会因为本次 README 整理而迁移。

## 常见问题

### 识别结果留在下方，没有进入正文

通常是识别期间正文发生变化。核对保留结果，选择插入、重试或丢弃，避免覆盖自己的编辑。

### 无法开始听写或没有声音

检查详情中的实际／目标版本、迁移提示、模型准备状态、凭据状态和设备选择，再检查系统麦克风权限。云端还需要服务可访问且账号可用。

### 为什么本地识别没有临时预览

本地服务按句返回结果。要使用临时预览，需要选择当前已支持的火山流式识别服务并完成相应配置。
