# Design

## Context

根已确认 upgrade-dsh-021-rc3-v2，本库采用实际 rc3 SDK／carrier，业务仍依本库现行规格。

## Goals / Non-Goals

目标是新精确组合兼容；不新增业务流程，不迁移数据目录或自动清除未知配置。

## Decisions

- 包版本为 0.2.1-rc.3+rev.1，官方 peer 依据实际 rc3 包；原始需求／旧 SPEC 不改。
- 宿主门禁保留精确检查，缺服务／包不豁免；新版共享语音和原生更多菜单按实际使用点回归。
- 保持配置所有者、有效字段、disabled 和现有业务存储；同版本 metadata 不替代内容校验。
- 验证用独立 rc3 SDK 及合成隔离数据；先必要类型／测试／构建，再原生组合验证，本机交付由根冷备份事务负责。
- 源码完整 SHA、运行文件和资源一致后提交；公开来源和真实外部服务另记，不复用 rc2 验收。

## Risks / Trade-offs

- [新宿主接口或共享服务不一致] → 补有区分力的回归并核对目标 SDK，失败保留真实诊断。
- [未知旧配置] → 保留并检查引用，遇并发拒绝覆盖。

## Migration Plan

更新精确依赖／运行门禁及必要兼容代码，执行既有检查并更新完整产物；安装保留原配置和数据，失败按根事务恢复本次写集。
