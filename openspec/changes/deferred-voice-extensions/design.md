# 候选设计与未决项

## Context

历史原文只读保留，当前实现契约见本库 openspec/specs 与 MIGRATION.md。本文件不把候选接口、配置键或命令描述为已经可运行。

## Goals / Non-Goals

目标是保留历史需求并建立后续细化、确认、实现和验证入口；本轮不开发业务、不改数据、不安装、不运行任务。

## Decisions

- 对话需另定发送确认、取消/打断及Session/Tool/Skill/Memory语义，普通听写不能隐式自动发送。
- 声学唤醒不同于文字前缀；常开麦授权、误触发、资源和本机模型来源需明确。
- 浏览器echoCancellation不等于完整AEC；Playback Reference/全双工/Speech-to-Speech需独立设计和真实设备验收。
- 原自动重连愿望已被较新已确认“失败不自动重传/切Provider”替代，本候选不恢复。
- 官方SenseVoice本地STT、人声打断和摘要已实现，主规格保留，不是本变更新增。
- 原文每条历史助手消息朗读仍候选，不以UI建议冒充最新消息之外已实现。
- 声源身份、本地TTS、新Provider、Profiles、强分类器、翻译与跨应用需逐项明确数据/权限/配置迁移。

## Risks / Trade-offs

历史愿望并非完整设计，不能用空缺处的默认推测替代用户确认。任何接口/配置/存储变化需列明旧值去向、失效字段清理、完整引用、备份、CAS、恢复与回滚；不静默改已有资料。

## Migration Plan

目前无业务迁移执行计划。文档版确认后再设计实际数据迁移，先预览、验证备份和冲突，实施状态与实测证据分开记录。

## Open Questions

需选择能力并定义发送门槛、常开麦授权、波形、AEC指标/设备、模型来源、档案覆盖策略与外部权限；无默认实现承诺。
