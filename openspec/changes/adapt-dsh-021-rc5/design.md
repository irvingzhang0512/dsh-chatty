# Design

文档版：v1（2026-11-04）。实现状态：待实现；具体文档确认：待确认。

## Context

范围见[proposal](proposal.md)；业务唯一源为[迁移表](../../MIGRATION.md)及现行chatty-delivery-boundaries。本库实现接缝为[compatibility.json](../../../compatibility.json)，不改原需求与冻结SPEC。现有rc3适配证据只作历史参考。

## Goals / Non-Goals

在目标SDK与真实原生运行时支持rc5固定组合；不改变工具／服务协议、配置所有者或业务数据目录，不附带其他待确认需求。

## Decisions

- 精确核对目标实际官方包版本，更新engines、peers、开发依赖和运行门禁；不能只改package声明或跳过真实peer测试。
- 重点实现／验证：官方语音Bundle和四子包均为rc.5；manifest、compatibility与实际挂载一致，缺包或跨基线拒绝；保留转写、朗读和不自动发送的边界。
- API、配置与存储格式沿现行契约，没有本库业务字段改名／清理／搬迁；如发现必须新增语义，先补文档确认。保留未知配置、有效工具／模型／文件引用和原停用选择。
- 直接依赖只按实际声明更新ws与tsdown小版本；宿主React和类型按真实包对齐，不引入无关工具链大版本。Chatty继续零新增运行依赖。
- 隔离SDK及合成数据执行既有检查并重建完整lib、patch、locale、捆绑Skill等已声明资源；Git安装不依赖prepare/install构建。源码SHA与运行文件摘要由根新锁记录。
- 日常退出、冷备份、配置CAS、固定安装与回滚统一由维护事务执行；不在本库安装期修改用户profile，不将隔离测试数据写入日常。套件成员保持唯一来源。

## Risks / Trade-offs

- 旧精确门禁阻挡新宿主 → 保留精确检查并增加真实匹配／失配回归。
- 前台接缝或共享服务不一致 → 原生窗口和实际接口联调，缺服务保留诊断；外部服务未测另记。
- 依赖或构建产物漂移 → 逐库检查及完整固定SHA／文件摘要，不复用旧验证结论。

## Migration Plan

确认v1后完成适配与验证再独立提交，交维护入口固定来源安装；失败恢复软件与事务写集，后续业务资料不覆盖。旧rc3未完成验收不改为通过，源代码推送／公开获取与本机安装分别记账。
