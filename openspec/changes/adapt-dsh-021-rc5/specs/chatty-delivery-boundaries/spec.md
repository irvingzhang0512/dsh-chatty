# Spec Delta

## ADDED Requirements

### Requirement: rc5精确交付与运行验收

插件 SHALL 以0.2.1-rc.5+rev.1适配Desktop 0.2.1-rc.5，保持F016/F021原业务边界和完整Git产物。缺必需能力或版本不匹配时按原边界拒绝增强并给出诊断，不以放宽声明冒充兼容。

#### Scenario: 目标组合加载

- **WHEN** 从完整固定SHA安装到已核验rc5运行时
- **THEN** manifest、实际依赖和产物身份一致，原业务能力及入口可用；重点覆盖：官方语音Bundle和四子包均为rc.5；manifest、compatibility与实际挂载一致，缺包或跨基线拒绝；保留转写、朗读和不自动发送的边界

#### Scenario: 旧数据与重复加载

- **WHEN** 旧配置、停用选择和业务资料存在，或重复加载同一组合
- **THEN** 保留未知字段、有效引用和原存储，不重放历史任务、不复制业务文档；安装事务归维护入口负责

#### Scenario: 失配与卸载

- **WHEN** 必需宿主能力失配或插件被停用／卸载
- **THEN** 保留真实诊断并清理本实例注册，原业务数据保留；可选集成仍按既有软依赖边界处理

#### Scenario: 验证范围独立

- **WHEN** 只完成代码检查或隔离模拟服务
- **THEN** 只记录实际通过范围，不将其写成日常、真实外部服务或用户试用通过
