## 复验入口

开发命令与原生隔离见 [DEVELOPMENT](DEVELOPMENT.md)，固定 Git 与组合检查见 [INSTALL](INSTALL.md)。源码测试使用目标 peers；本机日志／录音／认证信息仅在忽略的专用 .local fixture，报告只保留汇总，不提交凭据或音频正文。

原生最终回归还覆盖 PCM 播放持有停止状态直到音源结束、取消确实停止排程音源，润色会话替换后同 epoch 也丢弃，200ms 分片与帧尾不丢的测试。缺 Bundle 激活的实际 carrier 仍返回诊断和配置卡，增强不启动。

运行检查以公开注册表和 Loader 生命周期判断服务加载／变更，不按上下文代理对象引用判断；相关代理变化与增强 Provider 缺失回归已覆盖。TTS 音量在复用 AudioContext 时也读当前值，模型摘要开关独立于润色；普通参数保存／迁移保护在途识别与合成。

最终原生回归再次通过三句累计／普通发送后的新一句、冲突、润色撤销、取消、会话切换；自动监听启用后实际新会话自动开麦、停止后释放。五标签两次保存也在最终代码读回成功。
