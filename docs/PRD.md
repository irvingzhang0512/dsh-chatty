# dsh-chatty 产品需求
文档版：`native-voice-enhancement-20261013-v5`；2026-10-13。用户已明确要求实施本计划并持续完成，文档同步后直接开发。目标 Desktop／官方语音 Bundle `0.2.0-rc.2`，Chatty `0.2.0-rc.2+chatty.1`；实际实现与验收分别记录，不能由需求确认推导为已通过。

## 1. 产品与界面
官方 Bundle 提供识别注册表、语言偏好、SenseVoice 模型准备与完整音频识别；Chatty 提供持续听写、云端真实流式预览、口令、安全草稿操作、润色、朗读及完整配置 UI。全部增强在一个 Chatty 包，不维护官方 Bundle 分支。

前台沿用现有 Chatty 听写／朗读按钮、状态、音量柱、dock 和“语音输入、语音输出、指令与草稿、界面、高级”五标签设置卡。原生输入框是唯一正文编辑处。组合层停用官方录音 UI，保留全部官方包和服务；不改写官方 DOM。

## 2. 功能与流程
- 持续听写：点击开始 → 每句按序识别并插入原生草稿 → 检查／撤销／润色 → 明确发送 → 继续下一条或停止。停顿仅结束一句；停止收尾末句，取消丢弃未完成句；默认不自动开麦。
- 识别：本地 SenseVoice 和硅基流动在分句结束后识别；火山 Agent Plan 可实时显示临时预览，只有正式最终结果进入草稿。识别失败不切供应商或自动重传。
- 草稿：保留手写与引用；版本冲突保留待插入结果。撤销、清空和润色只作用于可靠追踪的语音区间，不整段覆盖草稿。普通发送后下一句不恢复旧正文。
- 口令：保留发送、撤销、清空、润色、停止听写、朗读、停止朗读七类，默认整句匹配；可选文字前缀或关闭。临时结果不执行动作，重复 final 不重复执行。归一化后词语跨动作冲突不能保存。
- 润色：显式按钮／已启用口令触发；默认语音区间，夹有手写内容时选择一段，冲突保留原稿和结果；成功不隐含发送。
- 朗读：手动朗读最新助手回复，自动朗读独立设置。代码默认跳过，表格／长列表默认规则摘要，模型摘要需另行启用。停止、轮次取消或会话切换后旧音频不能播放。
- 打断：已开启持续听写时可检测人声并先停播；单独朗读不自动开麦。浏览器回声消除不宣称完整 AEC。
- 语音对话延期：不展示按钮，不恢复旧模式，不执行识别结束自动发送；只有明确点击发送／原生提交／已启用发送口令才提交。

## 3. 配置与迁移
官方 26 项优先列入当前设置卡，保持原所有者；全部有效增强项同样有查看、修改、校验、保存、重新加载和恢复默认入口。具体字段及默认值见 [CONFIG-UI](CONFIG-UI.md)，接口和迁移见 [实施契约](IMPLEMENTATION-20261013.md)。

识别偏好由设置卡配置表单写入官方所有者；官方普通参数通过公开配置编辑接口重载。保存逐所有者反馈，不把部分失败说成整体成功。云端参数分供应商保存，切换不重置其他供应商。凭据只显示引用名、状态和 Credentials 入口。

迁移先预览／备份，用户显式应用；冲突由用户选择，未知字段及无关设置保留。退役 auto_send、voiceChat、声学唤醒占位和旧经典参数，合并重复预览字段；保留独立自动朗读。重新保存不能复活旧键，恢复备份有并发保护。

## 4. 安装与版本
安装源为 [GitHub 仓库](https://github.com/irvingzhang0512/dsh-chatty)，正式使用固定 tag／完整 commit 的 repo URL，不依赖 tgz 或现场编译。目标包及四个子包与 Bundle 完整版本精确匹配，设置卡显示实际来源和匹配原因。

版本采用 `<Bundle版本>+chatty.<修订号>`；首版 `0.2.0-rc.2+chatty.1`，未来 tag `v0.2.0-rc.2+chatty.1`，未发布前不得称为可用远端地址。更新按同一基线下整数修订比较；安装／回退记录解析到的完整 commit。

## 5. 验收与边界
三句连续听写按序累计一次；普通发送后的第四句不带回旧字；手写、引用和冲突结果保留；partial、停录、润色、解锁不自动发送。全部配置逐项保存／读回／恢复；迁移失败可恢复。原生 Desktop、真人语音、真实云端、TTS、Git 来源安装分别记录证据。

不纳入本期：语音对话、声学唤醒、完整 AEC、Speech-to-Speech、本地 TTS、真实波形、翻译和跨应用控制。
