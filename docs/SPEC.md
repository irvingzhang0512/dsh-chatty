## F001 麦克风与本地分句

- 预期：点击开始、按句持续采集；浏览器重采样 16k 单声道 PCM16，VAD、句首缓冲、最长句及积压有界；默认不开机监听。停止收尾末句，取消使未完成代次失效。
- 验收：停顿多句按序累计；停止保留末句；取消／卸载释放采集；麦克风授权、选设备和处理参数单列真实设备验收。
- 实现依据：client-src/40-audio.js、45-stt.js。
- 状态：当前实现已落地；验收状态以独立记录为准。

## F017 官方详情增强配置与帮助（v3）

- 预期：入口为插件→官方→语音输入。在官方原配置与成员列表之后追加 Chatty 增强，74 项保留五标签；底部折叠“官方高级参数（补充）”编辑 API 2 项／本地模型22项，分别保存。官方原识别服务／语言2项即时保存，增强只读摘要补充其中文说明，不重复编辑。全部100项可达；14px／36px／24px原生布局、搜索目录、帮助、重置与弃稿行为保留。Chatty 自己的详情页只提供安装／版本及跳转，无重复表单。
- 边界：切页、刷新目录和凭据状态不丢未保存字段；原所有者与 CAS、部分失败契约不变。诊断和低频参数折叠，不增加同义配置或自动迁移。
- 验收：官方原控件与成员顺序保持；74＋24＋2覆盖；跨标签／高级折叠草稿、逐所有者保存／失败／CAS、浅深色／宽窄／键盘帮助；自己详情无配置表单且跳转正确。
- 状态：本版已实现；实际通过范围与待验项见独立验证记录。

## F018 模型与音色目录（v6）

- 预期：识别、朗读、润色／摘要均可搜索选择并显式刷新；内置目录、当前保存值和高级自定义入口并存。火山读官方公开正文；硅基用语音文档分类并结合模型 API；本地仅刷新官方注册／状态；LLM 复用 DSH 目录和公开发现服务，自定义兼容端点读 models。
- 边界：确定性解析型号字段／正文用途，不执行网页脚本，不用 LLM 猜型号；不混淆音色和样例文本。候选有来源、更新时间、适配状态；刷新不替换选择、不改推理配置、不试调、不新增协议。失败保留上一有效缓存，旧型号保留并说明。已知不兼容禁选，未知明确标记。音色保留自定义值，换模型不静默改音色。
- 验收：真实公开网页、解析改版／空列表／误识别／下线、请求取消与错误保留、无密钥回传、模型与音色选择及草稿保护。
- 状态：已实现；实际通过范围与待验项见本版独立验证记录。

## F019 打开当前凭据文件（v6）

- 预期：顶部打开凭据文件按钮经原生文本文件打开器打开当前挂载 credentials-local 的实际路径，包含自定义路径；仍提供折叠凭据管理，仅展示引用、配置状态与可写性。刷新状态不清空草稿。
- 边界：路径只由宿主读取实际提供者配置确定，不接受客户端路径，不下发文件正文；缺文件／提供者／原生打开器时说明原因，不自动创建或改权限。
- 验收：当前与自定义路径、无文件／非本地提供者、原生打开结果、非法客户端路径拒绝、密钥不入响应及日志。
- 状态：已实现；实际通过范围与待验项见本版独立验证记录。
